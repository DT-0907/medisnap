# Raw Idea: Clinical Mode AR UI for MedSnap

## Feature Description

Initialize a new spec for the MedSnap AR medical assistant. This is a hands-free AR application for Snap Spectacles that provides medical training guidance and clinical assessment support.

Based on the existing product documentation, we're building the core Clinical Mode feature that includes:
- Voice-activated patient assessment
- AR display of patient information cards
- Symptom recording and AI-powered diagnostic support
- Prescription safety checking with drug interaction warnings
- Text-to-speech responses for hands-free operation

The spec should focus on implementing the Clinical Mode state machine, patient card renderer, prescription UI, and mode manager components as defined in the Dev 2 task list.

## Context

This is part of a 48-hour hackathon project building an AR medical assistant for Snap Spectacles. The Clinical Mode is one of two primary modes (alongside Training Mode). This feature enables healthcare providers to perform hands-free patient assessments with real-time AI support.
